# Getting Started with Create React App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Available Scripts

In the project directory, you can run:

Adjust the input parameters in the form:
    1.Number of Chargepoints: Total EV charge points (1-100).
    2.Arrival Probability Multiplier: Probability percentage (20-200%).
    3.Energy Consumption: Energy consumed per EV (in kWh).
    4.Charging Power: Power per charge point (in kW).

View the updated calculations in the Results section.

### `npm start`
Once the packages are intalled with `npm install`\

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

Tech Stack
React: Component-based architecture.
CSS: For styling.
JavaScript: Core logic and calculations.
